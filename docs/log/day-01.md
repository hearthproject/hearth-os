# Day01 · 双语文档站上线

<p class="lead">把散落在路线图、分册和架构材料中的内容整理成可检索、可切换语言、适合长期维护的文档站点。</p>

## 今日完成

- 建立中文与英文双语页面，保持路径、标题层级和主要结构对应。
- 将原始路线图重组为开始阅读、产品、系统设计、交付路线和参考五个入口。
- 完成浅蓝色视觉、首页阅读路径和桌面/手机响应式布局。
- 将完整路线图、分册内容和自研边界保留为可追溯页面。

## 验证证据

- 中文与英文页面均能独立构建并在 GitHub Pages 访问。
- 站内链接、搜索、Mermaid 图和语言切换通过检查。
- 站内归档确认完整路线图与各分册内容都可继续追溯。

## 遇到的问题

- 路线图材料很长，直接搬运会让用户不知道从哪里开始。
- 中英文页面如果结构不一致，后续维护和搜索都会失真。
- 旧版本号容易让读者误以为文档本身就是产品发版。

## 决定与取舍

- 采用“产品路线图 + 主题页面 + 完整归档”三层结构，既降低阅读成本又保留原文。
- 不在文档界面展示旧文档版本；产品里程碑只保留 MVP-1 和 v1.0 这类开发目标。
- 视觉优先保证阅读和扫读效率，不用大量装饰挤占正文空间。

## 明日计划

- 将 Stage 0–6 继续拆成可独立施工和验收的增量页面。
- 增加开发日志入口和可持续维护的日志模板。
- 完成线上部署、移动端和侧栏展开行为验证。
