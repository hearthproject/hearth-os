# 日志模板

<p class="lead">新增 Day03 时先复制这份结构，再替换日期、完成项和证据；保持简洁，但不要让未验证的计划看起来像已完成。</p>

## 复制这份结构

```markdown
---
title: 'Day03 · 一句话主题'
description: '一句话说明今天的真实变化与证据。'
outline: [2, 3]
---

# Day03 · 一句话主题

## 今日完成
- 

## 验证证据
- 

## 遇到的问题
- 

## 决定与取舍
- 

## 明日计划
- 

## 相关提交
- 
```

## 命名与放置

- 中文文件放在 `docs/log/day-03.md`，英文文件放在 `docs/en/log/day-03.md`。
- 编号连续，标题使用“Day03 · 主题”，不要只写日期。
- 两个语言文件的标题层级、列表数量、表格行数和链接数量保持一致。
- 在同一天的记录中保留失败、回退和未解决问题，不只写完成项。

## 提交前检查

- [ ] 今日完成项都能指向代码、文档、构建、截图或线上页面。
- [ ] 明日计划和已完成事项分开。
- [ ] 中英文页面结构一致，站内链接可访问。
- [ ] 日志索引、侧栏和上一页/下一页内容已经更新。
- [ ] 没有把文档提交描述成产品正式发版。
