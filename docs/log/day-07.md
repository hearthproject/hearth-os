2026-11-10 是 Hearth 把“任务能跑”推进到“任务有契约、有交接、有上下文、有验收证据”的一天。当天 56 次提交涉及 522 个文件（+20,709/−52,818）：前半段补上目标预算、截止时间、停止条件、命令与 Git 验证器、审批参数绑定和不确定效果对账；后半段加入持久委派、沙箱、交接证据、渠道幂等、个人本体、Context Broker、标准意图和连接运行时，最后把评测 corpus、评测应用和场景运行器迁出主仓库。

当天文件删除量很大，主要来自评测栈迁出和模板解耦，不代表产品能力被移除。主仓库保留评测桥接、任务模板、产品服务和运行证据；评测 case、控制台、实验和场景证据改由独立仓库维护。

## 目标与完成证据

| 方向 | 结果 |
|---|---|
| 目标预算与停止 | 目标预算覆盖轮次、工具调用、Token、时长和人工分钟；截止时间、停止条件和复核策略进入调度，耗尽时暂停、降级或转人工 |
| 验证器 | 完成判定新增命令和 Git 验证器，支持文件、结构、人工和模型复核；命令在受限环境中运行，不能用验证器扩权 |
| 调度接入 | 调度器在任务准备结束时注入自定义验证器并保存完成报告；目标型任务没有结论不能关闭 |
| 交接证据 | 跨执行器交接后仍保留终态证据，旧代次迟到的结果不能覆盖新状态 |
| 界面 | 任务详情展示验收条件、完成结论、证据和缺失项，不再只显示执行器总结 |

## 委派、交接与沙箱

| 方向 | 结果 |
|---|---|
| 持久委派 | 父任务创建有界子任务，记录预算、工作区策略、父子关系、租约、心跳和失败状态；子任务通过调度器推进 |
| 工作区策略 | 只读、隔离写入和共享读取三种策略约束子任务能看到和写入的范围 |
| 沙箱 | 检查工作目录、读写路径、网络域、进程白名单和凭据边界；任何越界失败关闭并留下原因 |
| 交接包 | 记录目标、下一步、验收条件、证据、权限子集、上下文水位、代次和脱敏信息；验证通过后才允许继续 |
| 渠道幂等 | 飞书和其他渠道的入站事件按标识去重，重复投递不会生成两个任务、两次审批或两个子任务 |

## 个人上下文与注意力

| 方向 | 结果 |
|---|---|
| 个人本体 | 实体、别名、关系、状态、决定和承诺进入统一记录；状态冲突不会被静默覆盖，而是进入需要用户确认的注意力项 |
| Context Broker | 按聊天、任务、目标、交接和委派范围组装 Context Pack，分为必须知道、相关、可召回和已省略；支持引用展开和父包权限约束 |
| 记忆治理 | 记忆来源、可信度、污染状态、敏感度和有效期参与召回；合并可审计，遗忘传播到投影、版本、事件、同步和派生记忆 |
| 标准意图 | 用户长期关注的规则保存为标准意图；心跳根据意图和任务状态生成候选，说明为什么现在、下一步和不处理的后果 |
| 注意力预算 | 每日上限、安静时段、同类冷却、单目标和高优先级上限、忽略惩罚和 `NO_REPLY` 反馈共同控制打扰 |
| 连接运行时 | transport、subscription、dataFreshness 和 executionOwnership 分开；重连推进 generation，旧代次写入被拒绝，离线操作进入 outbox，缓存投影不冒充实时 |

## 审批、技能与调度边界

| 方向 | 结果 |
|---|---|
| 审批绑定 | 原生补丁、完全权限动作、GitHub 写入和 SMTP 发送都绑定解析后的真实动作；参数变化、过期和复用会使审批失效 |
| 不确定效果 | 断线或回执不确定的外部动作进入显式对账队列，用户可以选择确认、重试或放弃，不盲目重发 |
| 技能权限 | 技能按使用来源、权限范围和风险分级；过期技能可清理并回退 |
| 调度补跑 | 定时任务支持有界补跑和失败冷却，避免停机后一次补跑过多或失败后高频重试 |
| 测试 | 新增目标、完成判定、委派、交接、沙箱、渠道、连接、个人本体、Context Broker、注意力和审批绑定的回归测试 |

## 评测拆分与文档

| 方向 | 结果 |
|---|---|
| 评测独立 | 评测前端、评测服务、评测核心、case、场景运行器和文档迁到独立仓库 `hearth-eval`；主仓库只保留任务/判定桥接和受管 artifact 目录 |
| 模板解耦 | 产品任务模板不再依赖评测 corpus，主服务使用自己的示例输入和产物声明 |
| 产物根目录 | 任务产物统一落到产品 artifact 根目录，评测输入通过外部根目录授权 |
| 文档事实 | README、交付状态、执行器交接、评测指南和阶段说明同步到拆分后的事实；新增本页与 Day06 |

## 边界与下一步

- 目标完成判定已覆盖命令、文件、结构、Git、人工和模型复核，但主观质量、真实业务影响和真实外部回执仍需人工验收。
- 委派是单层的，没有递归子 Agent 团队；本地沙箱是路径、网络、进程和凭据策略检查，不是强隔离容器或虚拟机。
- 连接运行时已有 generation、离线 outbox 和缓存投影，但没有接入真实远程节点或手机，未完成真实断网重连与跨节点对账。
- 个人本体和 Context Broker 仍以本地启发式匹配和排序为主；真实长期个人数据、手机推送、远程接管和跨设备上下文一致性尚未验收。
- 评测栈已迁出主仓库，`hearth-eval` 中的真实实验和通过率尚未由本轮文档更新产生；主仓库测试不能替代独立评测。
- 同日运行 `npm test`：89 个测试文件、579 个测试全部通过；`npm run typecheck`、`npm run build` 和 `npm run docs:build` 通过。测试通过不等于真实用户、真实设备和长期运行验收完成。
