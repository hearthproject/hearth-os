## 如何新增一天

1. 复制[日志模板](/log/template)，按 `day-04.md`、`day-05.md` 的格式创建新文件。
2. 只记录已经完成并有证据的事项；计划放在“下一步”，不要写成已完成。
3. 在同名英文目录创建结构一致的 `docs/en/log/day-03.md`，保持标题层级和列表数量一致。
4. 把新日志加入本页表格，并在 `docs/.vitepress/config.mts` 的 `/log/` 侧栏增加一项。
5. 运行 `npm.cmd run docs:build`、链接检查和翻译结构检查，再提交与部署。

## 每日记录模板

```markdown
# Day03 · 一句话主题

## 今日完成
- 完成了什么用户可见或工程可见的结果

## 验证证据
- 构建、测试、截图或线上地址

## 遇到的问题
- 问题、原因与当前处理

## 决定与取舍
- 做了什么选择，明确没有做什么

## 明日计划
- 下一步可验收的事项

## 相关提交
- 提交哈希或链接
```

## 写作原则

- 一条记录对应一个真实变化，不把同一项工作拆成多条。
- 先写用户看到的结果，再写内部实现。
- 失败、回退和未解决风险要保留，不制造“全部完成”的假象。
- 日志只记录项目过程；产品版本与发版说明在真正发版时单独维护。
