# 第六阶段 · 多设备与长期运行

当前实现、已验证范围和明确留空项见[阶段二至六交付状态](/delivery/status)。

## 目标

第六阶段把单机产品扩展为可以长期运行、在多台设备之间保持一致、可备份、可迁移、可撤销的个人 Agent OS。多设备不是复制多个 Agent，而是同一套任务、记忆和授权在不同设备上继续使用。

本阶段分为四个小阶段：

| 小阶段 | 目标 |
|---|---|
| [6.1 多设备同步与切换](/delivery/stage-6/6-1) | 同一套任务和产物在不同设备上保持一致。 |
| [6.2 设备撤销与安全迁移](/delivery/stage-6/6-2) | 设备丢失后可立即失效，更换设备时数据完整转移。 |
| [6.3 备份、恢复与升级](/delivery/stage-6/6-3) | 换机器、换版本或误操作都不丢任务、产物和记忆。 |
| [6.4 长期运行与 v1.0 验收](/delivery/stage-6/6-4) | 长期稳定运行，完成整体验收后发布 v1.0。 |

## 怎么做

1. 先让多台设备看到一致的任务和产物。
2. 再处理断网、设备切换和能力分配。
3. 然后补齐设备撤销、备份、恢复和升级。
4. 最后做长期运行和完整验收，形成 v1.0。
