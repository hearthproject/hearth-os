# 3.2 观察桌面与人工接管

## 当前状态

- **已实现：** 截图绑定当前会话；暂停、继续、接管、交还、终止；接管会取消待执行输入并推进控制代次；用户输入空闲检查和截图 2 分钟过期。
- **仍未完成：** 敏感区域遮罩、长期录像和完整桌面快照。

## 目标

让用户能看见 Hearth 正在操作的窗口和步骤，并在需要时暂停自动操作、自己接管、完成后再交还。

## 怎么做

1. 显示当前窗口、操作步骤和下一步计划，避免用户不知道系统在做什么。
2. 提供暂停、继续、接管和终止四个明确动作。
3. 用户接管时立即停止自动输入，交还时先确认当前状态再继续。
4. 对密码、聊天内容等敏感区域做遮挡，不把完整屏幕长期保存。
5. 记录每次接管、暂停和终止的原因，方便事后核对。
6. 如果无法观察窗口或无法接管，系统必须停下，不允许继续自动操作。
