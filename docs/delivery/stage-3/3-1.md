# 3.1 连接并查看桌面设备

## 当前状态

- **已实现：** 六位配对码、设备令牌、配对审批与能力审批分离；观察、控制、界面自动化逐项授权；应用白名单；在线状态和撤销设备。
- **仍未完成：** 托盘或全局常驻的“自动控制中”提示；目前仅支持 Windows 同机助手。

## 目标

让用户能把一台电脑安全地连接到 Hearth，并清楚看到这台设备能做什么、当前是否在线、允许操作哪些应用。

## 怎么做

1. 提供简单的桌面助手安装和配对流程，用户在 Hearth 里确认后才建立连接。
2. 显示设备名称、在线状态、可用的操作范围和最近一次活动时间。
3. 只允许用户明确选择的应用和窗口，不默认开放整个桌面。
4. 连接期间始终显示可见提示，用户能随时暂停或断开。
5. 提供撤销设备入口；撤销后设备不能继续操作或查看任务。
6. 用真实设备验证：用户能看懂权限范围，也能立即停止连接。
