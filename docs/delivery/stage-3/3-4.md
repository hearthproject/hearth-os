# 3.4 验收桌面操作

## 当前状态

- **已实现：** 在隔离端口完成配对、能力审批、观察、暂停、继续、接管、交还和专业版展开验证。
- **未完成：** 尚未用至少 5 个真实桌面任务完成成功率、接管次数和失败演练验收。

## 目标

用真实桌面任务证明第三阶段可用：用户能看懂、能接管、能停止，失败不会留下难以收拾的半完成状态。

## 怎么做

1. 选择至少 5 个真实桌面任务，覆盖不同应用和操作复杂度。
2. 记录完成率、接管次数、人工时间、失败原因和用户是否能理解系统动作。
3. 检查每次操作都有可见过程、验证结果和停止入口。
4. 检查高风险操作是否有影响预览、二次确认和补偿办法。
5. 做一次失败演练：窗口丢失、权限变化或用户接管时，系统能安全停下。
6. 只有当用户愿意在真实工作中使用，并且失败可恢复时，第三阶段才算完成。
