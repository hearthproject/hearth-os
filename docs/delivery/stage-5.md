# 第五阶段 · 记忆与能力进化

当前实现、已验证范围和明确留空项见[阶段二至六交付状态](/delivery/status)。

## 当前状态

- **已实现代码闭环：** 记忆候选、召回、纠正、冲突处理、遗忘传播与导出；候选方法从终态任务轨迹生成，经过试跑证据、评估、晋升、拒绝和回退。
- **仍未完成：** 真实长期记忆使用、错误记忆与错误方法演练、方法采用前后的生产对照，以及完整的 5.4 验收。逐项证据见[阶段二至六交付状态](/delivery/status)。

## 目标

第五阶段让 Hearth 积累个人背景并改进工作方法，但所有记忆都必须可查看、可纠正、可遗忘、可导出，所有新方法都必须经过评估、试用和回退。

本阶段分为四个小阶段：

| 小阶段 | 目标 |
|---|---|
| [5.1 建立可查看的记忆](/delivery/stage-5/5-1) | 记住有用的信息，并说明来源和用途。 |
| [5.2 纠正、遗忘与导出记忆](/delivery/stage-5/5-2) | 错误记忆可以改，敏感信息可以忘，全部数据可以带走。 |
| [5.3 总结并评估可复用方法](/delivery/stage-5/5-3) | 新方法先做候选，经过评估和小范围试用后才能采用。 |
| [5.4 验收记忆与进化](/delivery/stage-5/5-4) | 证明记忆和新方法真的有用，同时不会失控或无法回退。 |

## 怎么做

1. 先建立可查看、可纠正的记忆。
2. 再处理遗忘、导出和敏感信息边界。
3. 然后从真实任务中总结可复用方法。
4. 最后用评估、小范围试用和回退验收。
