# 1.2 做出完整体验原型

## 当前状态

- **已完成：** 用实际 Web 控制面走通了任务卡、审批、产物和失败恢复，覆盖排队、执行、等待审批、完成、失败与恢复等关键状态。
- **边界：** 原型没有伪造成功状态；未知、失败和无法完成都如实显示。

## 目标

做出一个覆盖完整使用路径的可点击原型，让用户在真正开发前就能看懂产品如何工作。原型必须包含任务卡、审批、产物和失败恢复，而不是只有首页。

## 怎么做

1. 设计四个主要入口：今日任务、需要你、产物、设置。
2. 覆盖任务从创建到结束的所有关键状态：排队、执行中、等待补充信息、等待审批、已完成、失败、可恢复、已取消。
3. 每个状态只保留一个主操作，并明确告诉用户下一步是什么。
4. 把任务卡、审批页、产物页和失败说明做成可以点击的完整流程。
5. 用假数据演示，但不要伪造成功；未知、失败和无法完成都要如实显示。
6. 请首位用户在电脑和手机上各走一遍，记录卡住和看不懂的地方并修正。
