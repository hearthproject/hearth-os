# 1.3 打通最小任务闭环

## 目标

在浏览器里打通最小真实任务闭环：用户创建任务后，系统能实际完成工作、请求必要审批、交出产物，并在失败时恢复或转人工。

## 怎么做

1. 做一个足够简单的本地服务和浏览器界面，先支持一个任务同时运行。
2. 创建任务时记录目标、输入、截止时间、可用范围和允许的动作。
3. 调用现成的执行能力在受控环境中完成真实工作，并持续显示进度。
4. 任务状态要能跨刷新和重启保留；失败后可以重试、继续或转人工。
5. 外部操作必须先展示对象、内容和影响，得到确认后只执行一次，并留下可核对的回执。
6. 产物要能保存、打开和追溯来源；失败要说明原因和下一步。
7. 限制系统可访问的文件、账户和网络范围，敏感信息不直接暴露给执行过程。
