# 1.4 用真实任务验收 MVP

## 当前状态

- **已完成：** 15 个真实任务完成验收，13 个通过；`npm test` 在 Day04 时为 40 个测试文件、198 个测试全部通过，`npm run typecheck` 和 `npm run build` 通过。
- **未完成：** T07 因测试文件未提交而失败，T08 的评论动作待批准；这两项是阶段一之后仍需补齐的边界。

## 目标

用真实任务证明 MVP 已经可以日常使用，并让它具备安装、启动、备份和退出的基本能力。完成这个阶段后，首位用户不依赖开发者也能独立使用。

## 怎么做

1. 用 1.1 确定的 15 个真实任务逐项验收，记录成功率、人工时间、失败类型和用户反馈。
2. 修复最影响使用的三个问题：任务丢失、失败无法恢复、审批或产物看不懂。
3. 提供简单的安装和启动方式，说明数据保存在哪里、如何备份和导出。
4. 增加全局停止开关和基础权限设置，让用户随时停下系统。
5. 让首位用户连续使用一周，收集真实使用中的问题和不愿继续使用的原因。
6. 只有至少 10 个任务通过验收、失败可恢复、用户愿意继续使用时，MVP 才算完成。
