# 2.4 验收日常内容工作

## 目标

用真实日常内容任务证明第二阶段的价值：用户花更少时间完成邮件、日历、文档和网页工作，同时仍能看懂、审批和恢复每一次外部操作。

## 怎么做

1. 选 10–15 个真实日常任务，覆盖邮件、日历、文档、表格和网页研究。
2. 记录每个任务的人工时间、成功率、审批次数、失败原因和用户是否愿意再次使用。
3. 检查每个结果是否有来源、能否核对，外部操作是否有回执。
4. 检查不同账户和项目之间没有数据串扰，敏感信息没有出现在不该出现的地方。
5. 修复最影响信任的问题：来源不清、审批信息不足、失败无法恢复。
6. 只有当用户愿意把日常内容工作交给它，并且人工时间明显下降时，第二阶段才算完成。
