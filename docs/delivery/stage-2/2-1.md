# 2.1 接入只读信息源

## 当前状态

- **已实现：** 本地文件、知识库和公开网页来源；域名白名单；来源状态、读取时间、错误、增量读取、去重、断开、重连和清除。
- **仍未完成：** 邮件和日历只显示“待配置”，没有账户凭据、读取或权限验证。

## 目标

让 Hearth 能安全地读取用户日常使用的信息来源，并把来源、时间和权限清楚地展示给用户。这个阶段只读，不发送、不修改、不删除。

## 怎么做

1. 先接一个邮件来源、一个日历来源、一个文件来源和一个知识库来源，不要一次铺开。
2. 每次读取都记录来源、时间、账户和权限范围，用户能查到信息从哪里来。
3. 对重复内容去重，对新增和变化做增量更新，避免每次全量重读。
4. 遇到登录失效、权限不足或来源不可用时，明确告诉用户，不要静默失败。
5. 提供断开来源和清除已读取内容的入口。
6. 用真实账户验证：用户能看到系统读了什么，也能确认系统没有写入。
