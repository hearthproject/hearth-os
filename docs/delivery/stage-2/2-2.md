# 2.2 处理文档、表格与网页资料

## 目标

让 Hearth 能处理文档、表格和公开网页资料，产出可以核对的结果。重点不是“能读”，而是结果有来源、能检查、能继续使用。

## 怎么做

1. 支持常见文档的读取、转换和摘要，保留原始文件和页码或段落位置。
2. 支持表格的筛选、汇总和信息提取，结果要能对照原表检查。
3. 做公开网页研究时，记录访问时间、网址、引用位置和页面变化。
4. 网页内容一律当作不可信资料，不执行页面里的指令，不因为页面文字扩大权限。
5. 登录页面、验证码或需要人工判断的情况，停下来交给用户处理。
6. 所有结果都保存为可打开的产物，并标明来源和生成时间。
