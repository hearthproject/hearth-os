# 6.3 备份、恢复与升级

## 当前状态

- **已实现：** 生成 `*.hearth-backup` 加密归档；scrypt 派生密钥，AES-256-GCM 加密；恢复先检查 `user_version`、schema 和 `integrity_check`，重建投影后再事务复制，失败回滚；旧 `/api/backup` 返回 `410`。
- **仍未完成：** 归档不包含产物正文、任务工作区、来源正文、发件箱附件和截屏，不是完整可迁移备份；没有版本升级流水线和真实跨版本恢复演练。

## 目标

让用户可以完整备份、恢复、导出和升级，不因为换机器、版本变化或误操作丢失任务、产物和记忆。

## 怎么做

1. 提供加密备份，包含任务、产物、记忆、设置和必要的授权信息。
2. 支持完整恢复和选择性导出，恢复后能核对内容是否齐全。
3. 升级前检查版本兼容性和空间，升级失败可以退回旧版本。
4. 迁移后验证任务状态、产物、记忆和技能仍然可用。
5. 提供清楚的备份位置、恢复步骤和失败说明，用户不需要开发者协助。
6. 用一次完整迁移演练验证：备份、恢复、升级、退回都能完成。
