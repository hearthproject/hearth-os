# 4.4 控制打扰与验收主动服务

## 当前状态

- **已实现：** 每日上限 0–50、安静时段、冷却时间、聚合窗口、临时暂停和恢复；预算快照显示今日已用、限额和下次允许时间；“需要你”页面集中显示待处理审批。
- **仍未完成：** 尚未用 5–10 个真实主动任务验收“平均每个任务打断不超过一次”；没有推送送达统计和长期用户感受记录。

## 目标

让主动模式安静、有用、可控，并通过真实任务证明它没有变成通知噪音。

## 怎么做

1. 设置每日打断上限、安静时段和同类事件聚合规则。
2. 提供随时暂停、降级和关闭主动模式的入口，并说明当前处于哪种模式。
3. 记录每条主动建议是否被接受、忽略或转成任务，以及用户是否觉得有用。
4. 用 5–10 个真实主动任务检验：平均每个任务打断不超过一次，用户能理解为什么被提醒。
5. 高风险动作仍然需要审批，手机审批不能被重复使用。
6. 如果用户开始关闭通知、忽略审批或觉得被打扰，先降低主动性，而不是继续增加功能。
