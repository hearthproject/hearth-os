# 4.1 设置触发条件与主动建议

## 当前状态

- **已实现：** 六类触发器：截止窗口、任务失败或可恢复、外部动作结果不确定、审批等待超时、来源出现新条目、队列积压或长任务；建议包含来源、原因、动作、影响、成本、风险和优先级，并按事件去重。
- **仍未完成：** 邮件和日历触发器只有禁用占位；主动模式只生成建议，不直接执行高风险动作。

## 目标

让 Hearth 能从用户授权的信息来源中发现值得处理的事情，并解释为什么现在需要用户关注。这个阶段只提出建议，不自动执行高风险动作。

## 怎么做

1. 从邮件、日历、文件和已有关注事项中产生候选事件。
2. 对重复事件去重，设置冷却时间，避免同一件事反复提醒。
3. 每条建议都说明来源、为什么现在重要、建议做什么、预计影响和是否需要审批。
4. 用户可以选择接受、忽略、稍后提醒或转成普通任务。
5. 先在不产生真实影响的情况下试运行，观察建议是否准确、是否过多。
6. 没有明确授权、预算或停止方式时，不开放主动执行。
