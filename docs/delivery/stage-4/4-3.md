# 4.3 手机查看、审批与接管

## 当前状态

- **已实现：** 可安装 PWA 壳、离线应用壳、移动底部导航和窄屏任务/审批页面已经存在；飞书长连接可以在手机上接收任务与审批消息，并执行 `/approve`、`/reject` 文本审批。
- **仍未完成：** 手机配对、iOS/Android 真机安装、系统级推送、远程接管和丢失设备撤销演练尚未验收。该小阶段仍是阶段四整体验收的前置条件。

## 目标

让用户在手机上完成最关键的查看、审批和接管，同时保证手机丢失后可以立即撤销，不把长期主权限放在手机上。

## 怎么做

1. 提供手机网页入口，支持查看今日任务、需要你处理的事项和产物。
2. 审批页展示真实对象、内容、影响和是否可撤销，关键操作要求再次确认。
3. 支持在手机上暂停、接管和终止任务，接管时立即停止自动操作。
4. 用短期配对码建立连接，手机不保存长期主权限；推送内容不包含敏感正文。
5. 手机丢失时可以立即撤销，撤销后不能继续审批、接管或查看任务。
6. 断网时只提供只读和明确的状态提示，恢复后再同步。
