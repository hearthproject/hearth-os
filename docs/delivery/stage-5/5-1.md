# 5.1 建立可查看的记忆

## 目标

让 Hearth 记住对用户真正有用的信息，并能说明每条记忆从哪里来、为什么被使用。用户必须能查看和修改这些记忆。

## 怎么做

1. 记录用户事实、项目背景、偏好、承诺和过去任务经验，但只记录有来源的信息。
2. 每条记忆都标明来源、时间、可信程度、适用范围和敏感程度。
3. 提供记忆浏览器，用户能看到记住了什么、最近在哪里被使用。
4. 任务使用记忆时，说明用了哪几条以及为什么相关，避免黑箱召回。
5. 只把任务需要的最小背景交给执行过程，不把所有记忆一次性塞进去。
6. 用户修改或删除记忆后，后续任务立即使用新版本。
