# 5.4 验收记忆与进化

## 目标

用真实使用证明记忆和新方法确实有帮助，同时不会带来错误召回、权限扩大或无法回退的风险。

## 怎么做

1. 检查记忆是否准确、来源是否清楚、纠正和遗忘是否生效、导出是否完整。
2. 至少让一个候选方法走完“提出—评估—小范围试用—正式采用—退回”的完整流程。
3. 记录采用前后的成功率、人工时间、成本和用户感受。
4. 检查新方法没有扩大权限，也没有把高风险动作变成自动执行。
5. 做一次错误记忆和错误方法演练，确认用户可以纠正并恢复。
6. 只有当用户能理解系统为什么记住、为什么采用，并且随时可以改回时，第五阶段才算完成。
