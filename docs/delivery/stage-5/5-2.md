# 5.2 纠正、遗忘与导出记忆

## 当前状态

- **已实现：** 纠正生成新版本并保留历史；同主题冲突必须选择左侧、右侧或合并；遗忘把当前记录改为墓碑并脱敏历史版本、相关事件和召回审计；导出不包含已遗忘正文，`secret` 记忆永不召回。
- **仍未完成：** 跨设备遗忘只通过同步过滤和本地副本边界保证；没有对已导出到外部文件的旧副本进行远程擦除。

## 目标

让错误或过期的记忆可以被纠正、遗忘和导出，并确保敏感信息不会在不允许的场景被使用。

## 怎么做

1. 当新旧记忆冲突时，保留来源和时间，展示冲突并采用用户确认的版本。
2. 删除记忆时，同时清理由它产生的摘要、索引和关联内容，避免从别处再次出现。
3. 提供完整的记忆导出，格式可读，用户可以带走或迁移。
4. 敏感信息只在明确允许的任务和场景中使用，不因为一次授权而永久放开。
5. 外部网页、邮件和文件内容不能直接写入记忆或扩大权限，可疑内容先隔离。
6. 用真实纠正和遗忘操作验证：用户删除后，后续任务不再使用旧内容。
