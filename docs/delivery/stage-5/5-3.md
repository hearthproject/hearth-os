# 5.3 总结并评估可复用方法

## 目标

让 Hearth 从成功任务中总结可复用的方法，但新方法只能作为候选，必须经过评估和小范围试用后才能成为正式能力。

## 怎么做

1. 从多次成功的真实任务中提取共同步骤，形成带适用范围和示例的候选方法。
2. 为候选方法准备成功样本、失败样本和对照结果，避免只挑好看的数据。
3. 先在不产生真实影响的情况下试运行，再在小范围真实任务中试用。
4. 试用期间比较成功率、人工时间、成本和失败类型，用户能看懂差异。
5. 新方法不能自动扩大权限，涉及高风险动作时仍然需要审批。
6. 保留旧版本，出现问题时可以立即退回。
