# Code Architecture

This section describes how Hearth actually works, derived entirely from the source code rather than from the original design documents. It is currently written in Chinese only; an English translation has not been produced yet.

[Open the Chinese overview](/architecture/)

## What it covers

Nineteen notes organised in five layers: the shared contracts and storage foundation, the task execution pipeline, context and knowledge, service assembly and governance, and the front end plus channel integrations. Each note declares its own boundary so that the same mechanism is not explained twice.

The pages under this path are language-switch landing pages. They exist so that switching the interface language from a Chinese architecture page does not lead to a missing page; the actual content lives in the Chinese section.
