# 3.2 Observe the desktop and take over

## Current status

- **Implemented:** Screenshots bound to the current session; pause, resume, takeover, handback, and terminate; takeover cancels pending input and advances the control generation; user-input idle checks and two-minute screenshot expiry.
- **Still open:** Sensitive-region masking, long-running recording, and full desktop snapshots.

## Goal

Let the user see which window Hearth is operating and what step it is on, then pause automatic operation, take over personally, and hand back when finished.

## How to do it

1. Show the current window, operation step, and next plan so the user is not left guessing.
2. Provide four clear actions: pause, continue, take over, and stop.
3. Stop automatic input immediately when the user takes over, and confirm the current state before continuing.
4. Mask sensitive areas such as passwords and chat content, and do not keep full screenshots for a long time.
5. Record the reason for every takeover, pause, and stop so it can be reviewed later.
6. If the window cannot be observed or the user cannot take over, the system must stop and must not continue automatically.
