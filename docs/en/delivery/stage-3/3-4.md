# 3.4 Accept desktop operation

## Current status

- **Implemented:** Pairing, capability approval, observe, pause, resume, takeover, handback, and Pro-expansion verification on an isolated port.
- **Still open:** No acceptance yet across at least 5 real desktop tasks for success rate, takeover count, and failure drills.

## Goal

Prove Phase 3 with real desktop tasks: the user can understand, take over, and stop, and a failure does not leave a difficult half-finished state.

## How to do it

1. Select at least 5 real desktop tasks across different applications and complexity levels.
2. Record completion rate, takeover count, manual time, failure reasons, and whether the user understands the actions.
3. Check that every action has a visible process, a verification result, and a stop control.
4. Check that high-risk actions have an impact preview, second confirmation, and compensation.
5. Run a failure drill: the system stops safely when a window is lost, permission changes, or the user takes over.
6. Phase 3 is complete only when the user is willing to use it in real work and failures can be recovered.
