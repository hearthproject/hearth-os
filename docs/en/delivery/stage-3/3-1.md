# 3.1 Connect and inspect a desktop device

## Goal

Let the user safely connect a computer to Hearth and clearly see what the device can do, whether it is online, and which applications it may operate.

## How to do it

1. Provide a simple install and pairing flow for the desktop helper; connect only after the user confirms in Hearth.
2. Show the device name, online state, available scope, and last activity time.
3. Allow only applications and windows the user explicitly selects; do not open the whole desktop by default.
4. Show a visible indicator while connected, and let the user pause or disconnect at any time.
5. Provide a device revocation entry; after revocation, the device cannot operate or view tasks.
6. Verify with a real device: the user understands the scope and can stop the connection immediately.
