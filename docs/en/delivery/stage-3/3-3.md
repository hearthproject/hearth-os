# 3.3 Complete desktop actions by risk level

## Goal

Let Hearth complete low-risk desktop actions in applications the user allows, and only then handle high-risk actions. Every step must be verified; looking finished is not enough.

## How to do it

1. Start with low-risk actions: open a file, find a menu, fill a draft, export a result.
2. Verify each step from window content and the change after the action; keep a screenshot as evidence when needed.
3. On failure, stop first and explain whether the window was lost, permission changed, input conflicted, or the result did not match; then retry or hand over.
4. For high-risk actions, preview the impact in an isolated desktop, require a second confirmation, and prepare a snapshot or compensation.
5. If the action is only half done, the window closes, or the user starts working, stop immediately and hand back.
6. Do not read password vaults, change system security settings, or perform irreversible actions without a recovery path.
