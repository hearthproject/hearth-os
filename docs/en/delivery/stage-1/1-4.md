# 1.4 Accept the MVP with real tasks

## Goal

Prove with real tasks that the MVP can be used every day, and give it basic install, start, backup, and exit capabilities. When this step is done, the first user can use it without the developer.

## How to do it

1. Accept against the 10–12 real tasks from 1.1, recording success, manual time, failure types, and user feedback.
2. Fix the three issues that hurt use most: lost tasks, unrecoverable failures, and confusing approval or artifacts.
3. Provide a simple install and start path, and explain where data lives and how to back up or export it.
4. Add a global stop switch and basic permission settings so the user can stop the system at any time.
5. Have the first user use it for a week and collect real problems and reasons they might stop using it.
6. The MVP is complete only when at least 8 tasks pass, failures can be recovered, and the user wants to continue.
