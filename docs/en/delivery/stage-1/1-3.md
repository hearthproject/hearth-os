# 1.3 Complete the smallest real task loop

## Goal

Complete the smallest real task loop in the browser: after the user creates a task, the system does real work, asks for necessary approval, delivers an artifact, and recovers or hands over when something fails.

## How to do it

1. Build a simple local service and browser interface; one running task at a time is enough.
2. When creating a task, record the goal, inputs, deadline, available scope, and allowed actions.
3. Use an existing execution capability to do real work in a controlled environment and show progress continuously.
4. Keep task state across refresh and restart; after failure, allow retry, continue, or human handover.
5. For external actions, show the target, content, and impact first; execute once after confirmation and keep a verifiable receipt.
6. Save artifacts so they can be opened and traced; explain failures and the next step.
7. Limit which files, accounts, and networks the system can reach, and do not expose secrets directly to execution.
