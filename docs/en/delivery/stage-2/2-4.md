# 2.4 Accept everyday content work

## Current status

- **Implemented:** Automated tests and isolated-instance verification of local sources, extraction, and the outbox chain.
- **Still open:** No acceptance yet across 10–15 real everyday tasks for time, accuracy, recovery, and user willingness.

## Goal

Prove the value of Phase 2 with real everyday content tasks: the user spends less time on email, calendar, documents, and web work while still being able to understand, approve, and recover every external action.

## How to do it

1. Select 10–15 real daily tasks covering email, calendar, documents, tables, and web research.
2. Record manual time, success rate, approval count, failure reasons, and whether the user would use it again.
3. Check that every result has a source and can be reviewed, and that every external action has a receipt.
4. Check that different accounts and projects do not leak into each other, and sensitive information does not appear where it should not.
5. Fix the issues that hurt trust most: unclear sources, insufficient approval information, and unrecoverable failures.
6. Phase 2 is complete only when the user is willing to hand over daily content work and manual time clearly drops.
