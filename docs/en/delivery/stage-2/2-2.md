# 2.2 Process documents, tables, and web material

## Current status

- **Implemented:** TXT, Markdown, CSV, JSON, HTML, PDF, DOCX, and XLSX text extraction with page, paragraph, sheet, range, and gap records; web snapshots and source entries can be reviewed.
- **Still open:** Complex layouts, scanned-document OCR, per-page citation anchoring, and spreadsheet formula fidelity.

## Goal

Let Hearth process documents, tables, and public web material and produce results that can be checked. The point is not just reading; the result must have sources, be reviewable, and be reusable.

## How to do it

1. Support reading, converting, and summarizing common documents while keeping the original file and page or paragraph locations.
2. Support filtering, summarizing, and extracting information from tables, with results that can be checked against the original.
3. For public web research, record access time, URL, citation location, and page changes.
4. Treat all web content as untrusted: do not follow instructions on the page or let page text expand permissions.
5. For login pages, captchas, or situations that need human judgment, stop and hand over to the user.
6. Save every result as an artifact that can be opened, with its source and generation time.
