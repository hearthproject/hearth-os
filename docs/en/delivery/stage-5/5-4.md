# 5.4 Accept memory and evolution

## Goal

Prove with real use that memory and new methods genuinely help, without wrong recall, permission expansion, or an inability to roll back.

## How to do it

1. Check that memory is accurate, sources are clear, correction and forgetting work, and export is complete.
2. Take at least one candidate method through the full path: propose, evaluate, small trial, adopt, roll back.
3. Record success rate, manual time, cost, and user experience before and after adoption.
4. Check that the new method did not expand permission and did not turn high-risk actions into automatic execution.
5. Run a wrong-memory and wrong-method drill to confirm the user can correct and recover.
6. Phase 5 is complete only when the user understands why something was remembered or adopted and can always change it back.
