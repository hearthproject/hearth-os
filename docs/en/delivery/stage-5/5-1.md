# 5.1 Create visible memory

## Goal

Let Hearth remember information that is genuinely useful to the user and explain where each memory came from and why it was used. The user must be able to view and edit these memories.

## How to do it

1. Record user facts, project context, preferences, commitments, and past task experience, but only with a source.
2. Each memory states its source, time, confidence, scope, and sensitivity.
3. Provide a memory browser where the user can see what was remembered and where it was recently used.
4. When a task uses memory, explain which items were used and why they were relevant; avoid a black box.
5. Give the execution only the minimum background the task needs; do not dump every memory into every task.
6. After the user edits or deletes a memory, later tasks use the new version immediately.
