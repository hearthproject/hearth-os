# 5.2 Correct, forget, and export memory

## Goal

Let wrong or outdated memories be corrected, forgotten, and exported, and ensure sensitive information is not used in disallowed contexts.

## How to do it

1. When old and new memories conflict, keep both sources and times, show the conflict, and use the version the user confirms.
2. When deleting a memory, also clear summaries, indexes, and related content derived from it so it does not reappear elsewhere.
3. Provide a complete memory export in a readable format that the user can take away or migrate.
4. Use sensitive information only in explicitly allowed tasks and contexts; one approval does not open it forever.
5. External web, email, and file content cannot write memory directly or expand permission; isolate suspicious content first.
6. Verify with real correction and forgetting: after the user deletes something, later tasks no longer use it.
