# 5.3 Summarize and evaluate reusable methods

## Goal

Let Hearth summarize reusable methods from successful tasks, but new methods start only as candidates and must pass evaluation and a small trial before becoming official capabilities.

## How to do it

1. Extract common steps from several successful real tasks into a candidate method with scope and examples.
2. Prepare success samples, failure samples, and comparison results for the candidate; do not cherry-pick favorable data.
3. Trial it without real impact first, then on a small set of real tasks.
4. During the trial, compare success rate, manual time, cost, and failure types in a way the user can understand.
5. A new method cannot expand permission automatically, and high-risk actions still require approval.
6. Keep the old version so it can be restored immediately if something goes wrong.
