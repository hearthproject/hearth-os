# 4.2 Build the proactive inbox

## Goal

Gather proactive suggestions in one place the user can handle easily, so it is clear what matters, why it matters, and what the user needs to do.

## How to do it

1. Create one proactive inbox grouped by importance and time; do not scatter suggestions across pages.
2. Each item shows the source, proposed action, expected impact, expected cost, and whether approval is needed.
3. Provide accept, ignore, remind later, and turn-into-task actions to avoid repeated interruption.
4. Support quiet hours, a daily limit, and batch handling so the user controls how often they are interrupted.
5. After the user ignores an item, do not rephrase and push it again; keep one record per event.
6. Test with real suggestions: the user can judge quickly and does not turn notifications off because there are too many.
