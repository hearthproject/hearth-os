# 4.1 Set triggers and proactive suggestions

## Current status

- **Implemented:** Six trigger types: deadline window, task failure or recoverability, uncertain external effect, approval wait timeout, new source entries, and queue backlog or long-running tasks; suggestions include provenance, reason, action, impact, cost, risk, and priority, and are deduplicated per event.
- **Still open:** Email and calendar triggers are disabled placeholders; proactive mode only creates suggestions and never executes high-risk actions directly.

## Goal

Let Hearth find work worth handling in sources the user has authorized and explain why it needs attention now. This step only suggests; it does not automatically perform high-risk actions.

## How to do it

1. Generate candidate events from email, calendar, files, and existing follow-ups.
2. Remove duplicates and add a cooldown so the same item is not raised repeatedly.
3. Each suggestion explains its source, why it matters now, the proposed action, expected impact, and whether approval is needed.
4. The user can accept, ignore, remind later, or turn it into a normal task.
5. Trial it without real impact first and observe whether suggestions are accurate and not excessive.
6. Do not enable proactive execution without clear authority, budget, and a stop control.
