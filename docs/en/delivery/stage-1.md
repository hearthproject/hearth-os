# Phase 1 · Minimum Complete MVP

## Goal

Phase 1 delivers the smallest complete product that a real user can use every day in a browser. It starts from 15 cross-industry real tasks and must pass at least 10 of them, covering the full path from creating a task through execution, approval, artifact review, and failure recovery. The goal is not broad coverage; it is proving that one task, approval, artifact, and recovery system works across multiple task families.

This phase has four steps:

| Step | Goal |
|---|---|
| [1.1 Define the first scenario and real tasks](/en/delivery/stage-1/1-1) | Define the first user, 15 real tasks, non-goals, and acceptance criteria. |
| [1.2 Build the complete experience prototype](/en/delivery/stage-1/1-2) | Walk through tasks, approval, artifacts, and recovery in a clickable prototype. |
| [1.3 Complete the smallest real task loop](/en/delivery/stage-1/1-3) | Let a task execute, ask for approval, produce results, and recover from failure. |
| [1.4 Accept the MVP with real tasks](/en/delivery/stage-1/1-4) | Make the first user independent of the developer. |

## How to do it

1. Choose the first user and 15 cross-industry real tasks, then define acceptance with real inputs.
2. Walk the full path and every important state through a clickable prototype.
3. Complete the real task loop: execution, approval, artifacts, and failure recovery.
4. Have the first user use it for a week and accept the MVP with at least 10 of the 15 tasks.
