# 项目与对话

Hearth 的对话分成两类：归属某个固定项目的项目对话，以及不依赖文件夹的独立对话。两者共享同一套任务、审批、记忆和产物链路，区别只在默认工作目录和文件权限。

## 项目

- 项目 = 名称 + 一个本地文件夹，不要求是 Git 仓库。
- Git 仓库根目录：自动记录默认分支，任务在独立 `hearth/<task-id>` Worktree 中执行，改动可以回滚。
- 普通文件夹：任务直接在该目录执行，结束后生成一份“新增 / 修改 / 删除”清单写入会话消息。
- 删除项目不会删除对话：相关对话自动转为独立对话，历史保留。
- 项目路径、分支和可用性每次读取时实时检查。

## 项目对话

- 创建对话时选择项目，之后不可更改，避免上下文和权限中途变化。
- 侧边栏按“项目 / 最近”分组；项目标题左侧可以直接新建对话。
- 新对话页显示项目名，并提示在该项目中构建什么。
- 任务自动使用项目路径，不需要每次手动选择工作目录。

## 独立对话

- 默认没有文件访问权限，适合纯问答、写作和通用任务。
- 如果消息中出现本机绝对路径（`D:\work\notes` 或 `\\server\share`），该文件夹会作为本次任务的工作目录，并在确认卡片和任务详情中展示。
- 消息中的路径必须真实存在；指向文件时自动取其父目录。

## 与 OpenViking 的关系

知识库是可选的本地服务，不随安装包分发。项目、任务和对话在未安装 OpenViking 时完全可用；安装入口位于首次配置的“知识库（可选）”步骤和设置 → 知识库。
