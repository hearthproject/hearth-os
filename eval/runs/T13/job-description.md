## 岗位简介

云帆数据正在招聘一名高级后端工程师（AI 平台），加入平台工程组，向平台工程负责人汇报。该岗位的核心工作不是单独编写一个模型调用，而是把 LLM 能力可靠地接入现有 API：重视结果校验、失败降级、可观测性和成本控制。

客户会处理敏感业务数据。因此，工程方案必须划清模型与生产数据的边界：密钥不能放在业务代码里，也不能让模型直接修改生产数据。岗位前期为个人贡献者，不承担算法研究或团队管理职责。

## 岗位职责

以下职责为对访谈内容的归纳；具体服务所有权、系统边界、SLA 和上线指标**待确认**。

1. **将 LLM 能力接入现有 API：** 参与设计、实现和维护面向客户产品的后端服务，把 LLM 能力接入既有 API，而不是停留在单次模型调用。
2. **设计可恢复的异步与长任务：** 面向耗时较长、涉及多个步骤或外部依赖的任务，设计可靠的任务编排、状态管理、失败恢复和人工介入机制。
3. **建立结果校验与数据写入防线：** 校验模型输出，处理异常或不可信结果，避免错误输出污染业务数据；确保模型不能直接修改生产数据。
4. **设计失败降级：** 面对第三方服务超时、不可用或响应异常，提供受控重试、替代路径或有明确边界的降级结果，保证系统可解释、可恢复。
5. **落实安全边界：** 密钥不进入业务代码；对敏感业务数据实施必要的访问控制与数据保护；具体合规要求、数据驻留和供应商条款**待确认**。
6. **建设测试与可观测性：** 为异步流程、外部依赖和非确定性输出建立测试策略、日志、指标、追踪和告警，使故障可以被发现、定位和复盘。
7. **控制成本并做工程取舍：** 在质量、延迟、可靠性和调用成本之间做有依据的取舍，建立成本可见性和必要的预算保护。
8. **编写可执行的文档：** 遵循团队简洁的写作风格，产出能直接指导实现的接口、流程和运维文档。

## 必需项（Must-have）

1. **后端经验：** 5 年以上后端开发经验。工作年限的具体认定口径（例如实习、外包或项目经历如何计算）**待 HR 确认**。
2. **Python 与 FastAPI：** 熟悉 Python 和 FastAPI，能够独立设计、实现和维护后端 API。
3. **SQL 能力：** 能独立完成查询编写与索引优化，并能解释查询计划、索引选择和性能取舍。
4. **异步或长任务经验：** 做过异步任务或长任务，理解任务状态、重试、幂等和恢复等可靠性问题。
5. **LLM 或复杂第三方 API 经验：** 最好做过 LLM 应用；如果没有 LLM 应用经验，至少要有复杂第三方 API 集成经验。
6. **安全与数据边界意识：** 认同并能够落实“密钥不放在业务代码中”“模型不直接修改生产数据”的工程约束。
7. **可靠性设计能力：** 能围绕结果校验、失败降级、可观测性和成本控制设计并交付可维护的后端方案。
