# T13 输入：云帆数据招聘需求访谈记录

- 公司规模：20 人，B2B 数据产品
- 团队：平台工程组，现有 4 名工程师、1 名产品经理、1 名设计师
- 岗位：高级后端工程师（AI 平台）
- 职级：P5，向平台工程负责人汇报
- 工作地点：上海优先，可接受中国时区远程
- 薪资范围：不对外公开
- 面试流程：筛选、技术面试、系统设计、团队面

## 访谈摘录

“我们需要一个人把 LLM 能力接进现有 API，但不是只写一个调用。重点是结果校验、失败降级、可观测性和成本控制。我们的客户会处理敏感业务数据，所以不能把密钥放到业务代码里，也不能让模型直接改生产数据。”

“必须项是五年以上后端经验，Python 和 FastAPI 要熟，SQL 要能独立做查询和索引优化，做过异步任务或长任务。最好做过 LLM 应用，但如果没有，至少要有复杂第三方 API 集成经验。”

“加分项是做过评测集、提示词版本管理、供应商切换、向量检索或账单成本分析。我们不需要算法研究背景，也不需要带团队，前期是个人贡献者。”

“团队写作风格简洁，文档要能直接指导实现。面试重点看：如何设计可恢复的长任务；如何防止模型输出污染数据；怎么做测试和观测；遇到供应商超时怎么降级。”

## 输出要求

- 生成 `eval/runs/T13/job-description.md` 和 `eval/runs/T13/interview-kit.md`。
- JD 必须区分职责、必需项、加分项和不在岗位范围内的内容。
- 面试题必须覆盖长任务恢复、输出校验、供应商故障、数据安全、测试与观测、成本取舍。
- 每道题给出能力维度、评分锚点和追问建议。
