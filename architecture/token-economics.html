TOKEN ECONOMICS

Token 经济 ​

目标不是单纯少用 Token，而是让每次有效完成更省。Token 是架构约束，不是事后账单。

Token 经济 ​

目标不是“少用 Token”，而是“每次有效完成更省”。Token、成本、延迟和人工分钟必须一起看，不能通过降低质量制造虚假节省。

预算层级 ​

text
全局日预算
  → 用户/项目预算
  → Task 预算
  → Run 预算
  → Step 预算
  → 单次上下文注入预算
  → 输出 Token 预算

预算包括 Token、成本、时间、工具调用次数、网络请求和人工打断。任何一级耗尽都必须暂停、降级或转人工，不能静默透支。

Token Governor ​

Token Governor 是跨执行器的成本控制面：

  • 规则优先：不需要模型的任务直接走确定性路径；
  • 任务分类：判断任务族、复杂度、风险和隐私级别；
  • 模型目录：维护能力、价格、延迟、上下文和可用性；
  • Context Compiler：构建最小充分上下文；
  • Router：按预期成功率/成本选择执行器；
  • Cache：复用解析、检索、摘要和已验证产物；
  • Meter：实时记录输入、输出、缓存和工具开销；
  • Watchdog：发现异常消耗、循环和预算超支；
  • Attribution：把成本归因到任务、项目、技能和执行器。

Context Compiler ​

Context Compiler 把“系统知道的一切”压缩成“这次任务真正需要的证据”。Context Pack 通常包含：

  1. 目标和验收标准；
  2. 当前任务状态；
  3. 用户明确约束和偏好；
  4. 相关事实与来源引用；
  5. 必要文件片段和 artifact 引用；
  6. 可用工具和权限；
  7. 输出 schema；
  8. 预算和截止时间；
  9. 已知失败和禁止路径；
  10. 需要人决策的问题。

规则：

  • 不把完整聊天历史当上下文；
  • 不把完整邮箱、仓库或网页塞入；
  • 长材料先索引、分页、检索和摘要；
  • 只保留有来源的断言；
  • 用稳定前缀和缓存友好结构复用系统提示；
  • 摘要不能丢掉关键限定条件、数字和引用；
  • 任务结束后清理 Working Memory。

模型与执行器阶梯 ​

层级能力典型用途成本策略
T0 确定性规则、SQL、脚本、API、diff过滤、转换、对账、读取不调用模型
T1 本地分类器小模型、embedding、规则模型分类、优先级、实体识别本地、低延迟
T2 小模型短上下文、结构化输出摘要、提取、短草稿按量、严格上限
T3 Native 大模型通用推理与工具短链路规划、复杂分类中等成本
T4 Codex长链路、多文件、复杂产物代码、研究、长文档高成本、强验证
T5 Human判断、责任、接管高风险、歧义、不可逆最稀缺，需预算

路由按任务形态、历史成功率、隐私和成本动态选择，不按工具偏好。

增量读取 ​

优先使用文件 diff 和版本比较、增量同步和游标、按页/段/表/行检索、文档索引和引用定位、结构化字段提取、重复材料摘要、artifact 引用、相关代码文件和测试结果、网页可访问性树和页面 diff。

缓存、批处理与本地模型 ​

  • 缓存解析、检索、摘要、embedding 和已验证产物；
  • 能批量聚合的低价值任务不逐条调用大模型；
  • 隐私敏感、低延迟或离线任务优先本地模型；
  • 本地模型不是免费：仍要计算延迟、维护和质量成本；
  • 缓存必须有版本、失效和删除策略，不能复活已遗忘内容。

硬预算与异常停止 ​

  • 每级预算有硬上限；
  • 循环、重复工具调用和异常上下文增长触发 Watchdog；
  • 预算耗尽后暂停或降级，不静默继续；
  • 用户能查看“为什么花这么多”；
  • 人工打断也是成本；
  • 高风险任务不能为了省预算跳过验证。

成本归因与指标 ​

  • 每任务、项目、执行器、模型、技能和用户可见动作的成本；
  • Verified Success per dollar；
  • Token per verified task；
  • 人工分钟与 Token 的联合下降；
  • 缓存命中、重复读取和无效重试；
  • 异常消耗和预算停止次数。

反模式 ​

  • 只优化 Token，不优化人工分钟和成功率；
  • 用更小模型反复失败；
  • 把所有记忆和全文塞入上下文；
  • 用自然语言摘要替代结构化提取；
  • 重试不设上限；
  • 缓存污染；
  • 隐藏成本；
  • 为省模型调用跳过验证或审批。

默认策略 ​

  1. 能规则/脚本就不调用模型；
  2. 能结构化就不生成自然语言；
  3. 能引用 artifact 就不重复全文；
  4. 能小模型就不大模型；
  5. 能缓存就不重复；
  6. 能停止就不过度重试；
  7. 能转人工就不做高风险无人值守。
