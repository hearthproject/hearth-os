SECURITY & PRIVACY

安全与隐私 ​

安全不是发布前检查，而是产品能力。信任边界、Capability、风险分级、凭据和事故响应都必须在架构中体现。

安全是产品能力 ​

Hearth 的安全不是“加一个审批弹窗”，而是贯穿来源、上下文、权限、执行、副作用和恢复的系统能力。模型不是可信执行环境，网页不是可信指令，文档不是可信代码，Connector 返回的数据也不是自动可信。

信任边界 ​

text
不可信外部内容
  → Gateway 归一化
  → Policy / 数据标记
  → 最小上下文
  → Executor
  → Sandbox
  → Effect Dispatcher
  → 外部系统

每一层都假设下一层可能被污染。外部内容可以影响任务内容，但不能扩大权限、修改 Policy 或直接触发高风险副作用。

威胁场景防线
提示词注入网页/邮件要求泄露文件或忽略规则数据指令分离、工具白名单、不可信标记

Capability 模型 ​

Capability 不是“某个 Agent 有某个工具”，而是对具体资源、动作、范围和期限的许可：

ts
type Capability = {
  action: string;
  resource: string;
  scope?: Record<string, string>;
  constraints?: Record<string, unknown>;
  expiresAt: string;
  revokedAt?: string;
  issuedBy: string;
  mandateId: string;
};

原则：最小权限、短期有效、任务结束回收、按设备/账户/资源/动作限定、执行器不能自签或扩大、所有使用可审计、撤销立即生效。

风险分级 ​

等级示例默认处理
R0 只读查看文件、读邮件、搜索可自动
R1 低风险写入草稿、临时文件、工作区修改在 Mandate 内自动
R2 外部可见发送邮件、评论、分享首次或每次审批
R3 不可逆删除、付款、权限变更、公开发布强审批 + 回执 + 补偿
R4 禁止绕过安全控制、泄露秘密、未经授权转账系统拒绝

凭据与秘密 ​

  • 长期秘密只存在 Broker/密钥库；
  • 模型上下文永远不包含 refresh token、私钥、cookie；
  • 短期 token 只在调用外部 API 时注入；
  • 日志、异常、截图和 Artifact 做敏感信息扫描；
  • 开发、测试和生产使用不同凭据；
  • 本地存储和备份加密；
  • 支持按连接、设备和账户撤销；
  • 用户可查看“谁在什么时候用了什么权限”。

Sandbox、网络与提示词注入 ​

  • 默认最小挂载和最短生命周期；
  • 默认拒绝出站，按任务开白名单；
  • 外部页面和文档标记为不可信；
  • 不可信内容不能直接决定工具调用；
  • 高风险动作必须经过 Effect Dispatcher 和审批；
  • 下载物、宏和附件进入隔离区；
  • 沙箱失败视为安全事件，不做“再试一次”掩盖。

隐私与本地优先 ​

  • 默认本地存储；
  • 只上传任务需要的最小上下文；
  • 敏感数据可指定本地模型或人工处理；
  • 记忆、日志和 Artifact 有敏感级别；
  • 删除和遗忘要传播；
  • 备份加密；
  • 数据导出和迁移可用；
  • 不把用户数据用于未经同意的训练或共享。

供应链与扩展 ​

  • 依赖锁版本、校验、SBOM；
  • 技能/插件签名或来源验证；
  • 第三方 Connector 最小权限；
  • 插件不能绕过 Policy；
  • 高风险扩展需人工审阅；
  • 升级前跑安全与契约测试。

多设备安全 ​

  • 设备配对使用短期码和公钥；
  • 手机不持有长期主凭据；
  • 审批绑定 nonce、参数和过期时间；
  • 设备丢失可远程撤销；
  • 离线缓存只读，不产生外部副作用；
  • 跨设备只同步必要投影和产物引用；
  • 记忆删除不能在另一设备复活。

事故响应与 kill switch ​

  • 全局停止开关；
  • 按设备、连接器、技能、任务和账户的局部停止；
  • 停止后保留审计和恢复入口；
  • 密钥轮换；
  • 事故后清理受影响凭据和缓存；
  • 输出可读的事故报告；
  • 不把“重启服务”当成事故处理。

备份、恢复与删除 ​

  • 加密备份；
  • 恢复后验证事件、产物、记忆和权限；
  • 删除传播到投影、索引、缓存和设备；
  • 保留最小审计所需信息，但不保留不应保留的敏感正文；
  • 用户可导出自己的数据；
  • 迁移后重新验证，不假设复制成功。

安全测试 ​

  • 提示词注入与工具越权；
  • 秘密泄漏；
  • 路径穿越、宏、zip bomb；
  • 沙箱逃逸；
  • 网络出口绕过；
  • 审批重放；
  • 设备撤销；
  • 重复副作用；
  • 供应链篡改；
  • 记忆投毒；
  • 数据和备份删除。
