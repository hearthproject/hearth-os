Hearth OSTurn digital labor into reliable tasks

A single-user, self-hosted, long-running personal Agent OS. Durable execution, real tools, explicit approvals, and verifiable receipts turn intent into results you can confidently deliver.

Capabilities

Not a chat box, but a complete task path

From intent, proposal, execution, and approval to receipts and recovery, every step leaves a record that can be checked. Models and executors can change; task state and evidence do not disappear.

01Chat-first control planePropose a task in conversation, confirm permissions in a proposal, and inspect executor, budget, checkpoints, and artifacts in task detail.→02Native agent runtimeA self-built single-agent tool loop that unifies four model protocols with built-in read, search, write, command, web, ask, and finish tools.→03Tasks and durable executionA state machine, budgets, checkpoints, waiting-for-input, resume, and retry let work continue across restarts and failures.→04Approvals and external effectsExternal actions are previewed, one-time approvals bind to a parameter fingerprint, and the effect ledger executes once and stores a receipt.→05Sources, documents, and outboxLocal files, knowledge bases, web pages, and document formats enter tasks with provenance; writes land in the local outbox first.→06Desktop, memory, and multi-deviceWindows pairing and takeover, a proactive inbox, correctable memory, method evaluation, and incremental sync with leases and revocation.→

Architecture

Facts land first; the interface is a projection

One process, one writer, one local database. No premature microservices and no second source of truth.

Quick start

Running in three minutes

Requires Node.js 22.13+. Vite proxies /api to 127.0.0.1:4317.

bash
git clone https://github.com/hearthproject/hearth-os.git
cd hearth-os
npm ci
npm run dev
